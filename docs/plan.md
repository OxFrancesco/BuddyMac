# BuddyMac migration

Scope: BuddyFiles, BuddyTalk, BuddyWrite, NotchFlow, BuddyDock and Liny. Jesty is excluded. Original applications, stores and startup settings remain intact.

GPUix React owns the native window and primary controls. Bundled native services handle files, microphone capture, Accessibility insertion, SwiftData, notifications, icon application and the original Liny agent engine.

The six core modules are installed at `~/Applications/BuddyMac.app`, Developer ID signed. Final verification passed 62 service tests and 567 assertions, with one optional cached-model skip; a separate cached S1 check passed 12 assertions. Original native UI verification covered 11 workflows plus 4 Focus checks; the follow-up added 7 workflows and a real cloud rewrite through the installed UI.

The replacement OpenRouter key is saved in Keychain with a $5 total cap and 90-day expiry. Live cloud rewrite, transcription, cleanup, history and speech customization passed. Real Files drag-out passed with receiver bytes and source preservation. Native Liny actions and model-directed replacement passed with independent receiver readback under inherited helper permissions.

BuddyMac itself has microphone and notification permission. Five-second microphone recording/cancellation passed without uploading audio. Focus transitioned to the corrected short break and macOS reported a new delivered notification. Screen capture remains off at the user's request. Accessibility is off at the user's request; the installed-app insertion attempt failed and copied its fixture as fallback. Earlier helper insertion is not proof of BuddyMac's own permission.

Full original feature parity remains incomplete. See `docs/parity.md` and the per-module feature coverage artifacts for gaps. The follow-up report distinguishes service checks, fixture UI checks, real provider requests and independent receiver evidence.
