# Installed feature verification

Scope: every implemented BuddyMac workflow across Files, Talk, Write, Focus, Dock and Liny. Separate missing original features from failed or unverified existing features.

1. Create a dedicated Personal OpenRouter key and save it through the signed speech helper. Keep the secret out of logs and source.
2. Verify live rewrite, generated-audio transcription, microphone start/stop/cancel, retry, vocabulary, snippets, memory, history and external insertion. Use synthetic content and restore test preferences.
3. Exercise native file delivery, edge/compact windows, focus alerts and Liny computer tools against a dedicated test target.
4. Expand fixture coverage for destructive operations, original-data preservation, timer transitions, icon application and session state. Fix failures and rebuild.
5. Re-run installed UI checks, save per-feature evidence and recording, update the private report and notify once.

Original app stores stay intact. Existing user conversations, files, icons and clipboard contents are not test fixtures. Microphone and screenshot tests are short and purposeful. Record permissions refused by macOS as blocked, never as passed.
