# Confirmed scope

User confirmed six tools: BuddyFiles, BuddyTalk, BuddyWrite, NotchFlow, BuddyDock, Liny.

Jesty is explicitly excluded. Liny was briefly excluded and then explicitly included. BuddyCam, Keyboard Clean, Clipboard Vault, Timy, Speakrec, Becket, and ManinVE remain inventoried candidates outside this implementation because there is no confirmed daily/weekly use.

BuddyMac must be a functioning native GPUix application, not a launcher for six existing interfaces. Existing apps, settings, recordings, and source repositories are preserved.
